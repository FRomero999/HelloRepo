# Hello World 2027
Proyecto de introducción al curso 2027

## Todo-List v0.1

Pequeña aplicación para gestionar lista de tareas desde la consola.

## Funcionalidad

1. Añadir una nueva tarea
2. Borrar una tarea
3. Listar las tareas completas
4. Marcar una tarea como completada

## Implementación

- Se usa la **última versión de java** Jdk27.
- Almacenamiento de tareas en memoria usando `ArrayList<>`
- Gestión del UI con `println` y `Scanner`
